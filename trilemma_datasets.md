## 2. What "API Key Required" Means

An API key is a credential (free in most cases) you get by registering with the data provider. Your code sends it with each request so the provider can apply rate limits and terms of use.

- Register early (Day 1) — some keys need email confirmation or manual approval.
- Never commit keys to GitHub. Put them in a `.env` file and add `.env` to `.gitignore`.
- "No key" datasets can be downloaded or queried directly — the fastest option for a one-week datathon.
